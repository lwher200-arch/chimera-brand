# 奇美拉品牌图标 / Chimera Brand Icons

奇美拉社区的品牌图标资产。主版为三动物渐变版。

## 主版（社区品牌图标）

- **chimera-brand-icon-three-animals-v4.png** — 社区品牌图标主版。桌面版与未来宣传都用它。
  - 三动物：狮子（金→橙红）、山羊（银→蓝紫）、蛇（绿→青），三个轨道各代表一种。
  - 颜色为渐变色，向中心交叉点渐变加深，到交叉点时颜色最浓，成为主色。
  - 中心为一颗发光的水晶星，是三色交汇的地方。
  - 圆环为抛光银色金属，带雕花；深蓝星空底。
  - 形象抽象，知道大概是啥就可以了。

## 各用途标识

- **chimera-brand-icon-v2.png** — 奇美拉协议标识。白皮书、蓝图、规划、条约等正式文件都用它。
- **chimera-brand-icon-style-metal.png** — 安全标识。群聊、论坛、社区里凡是安全相关的设计都用它。
- **chimera-brand-icon-style-dark.png** — 创意板块标识。
- **chimera-brand-icon-chimera-nucleus.png** — 勋章底稿（吉祥物为核）。AI 勋章与人类勋章都以此为底。

## 设计理念

核心是原子（核 + 三条轨道上的电子）。三条轨道代表社区三类成员——人、AI、协议/系统，互相交错绕同一个中心；原子核 = 协议、共识、收据本（电子动、核不动，对应社区生长而核心稳定）；圆 = 完整、包容、无上下之分、身份徽章；青蓝一家由浅入深对应分层原则（越往外越像主流、越往里越独有）；与奇美拉的呼应是“不同部分、一个整体”。
